実験の概要

この実験では、「地球」と「惑星」という2つのテーマを通して、自然現象を微分方程式でモデル化し、 それをコンピュータで数値的に解いて可視化する、という一連の流れを体験します。 第1回・第2回は地球のエネルギー収支（気候モデル）、第3回は惑星の運動（重力多体問題）を扱います。 各回の資料は、下のカードまたは上部のメニューから、回ごとのページで開いてください。

この実験の進め方について 毎回、まず「解きたい微分方程式」とその数値解法（アルゴリズム）の数式を確認します。 次に、その解法を使ったごく簡単なテンプレートプログラムを配布するので、 まずはそのまま動かして挙動を確認してください。そのうえで、テンプレートプログラムの一部分だけを 改造して、その回の本題（気候モデルや惑星の軌道など）を解くプログラムに仕立てていきます。 「アルゴリズムを一から書く」のではなく「動くコードのどこを変えれば目的の現象を再現できるか」 を考えてみてください。

各回の資料

第1回 地球のエネルギー収支モデル 放射平衡の考え方で惑星の平衡温度を計算し、太陽定数を振ってT–S曲線を描く。 第1回のページへ → 第2回 Euler法とエネルギーバランスモデルの時間発展 Euler法を確認し、放射収支モデルの時間発展へ拡張する。発展課題で氷アルベドフィードバックとヒステリシスを調べる。 第2回のページへ → 第3回 惑星の運動（重力多体問題） 2体問題をEuler法で解き、リープ・フロッグ法に改造してエネルギー保存を比較。発展としてN体へ拡張。 第3回のページへ →

gnuplotのインストール（Windows）

Windows環境でのgnuplotのインストール方法を説明します。

  1. gnuplot公式ダウンロードページ（SourceForge） にアクセスし、最新版のフォルダを開いて、Windows用インストーラ （gpXXX-win64-mingw.exeのような名前のファイル）をダウンロードします。
  2. ダウンロードしたインストーラをダブルクリックして実行します。
  3. インストール中の「Select Additional Tasks」の画面で、 「Add application directory to your PATH environment variable」 に必ずチェックを入れてください。これを忘れると、PowerShellからgnuplotコマンドが使えません。
  4. それ以外の設定はデフォルトのまま「Next」で進み、インストールを完了させます。
  5. インストール後、開いていたPowerShellは一度閉じ、新しく開き直してから 以下のコマンドで動作確認をします。
動作確認（PowerShell）
gnuplot --version

バージョン情報が表示されればインストール成功です。もし 'gnuplot' は、内部コマンドまたは外部コマンド、操作可能なプログラムまたはバッチ ファイルとして認識されていません。 のようなエラーが出る場合は、PATHへの追加がうまくいっていません。インストーラをもう一度実行し、 手順3のチェックボックスにチェックが入っているか確認してください。

gnuplotスクリプトは、PowerShellでgnuplot ファイル名.gpのように実行します。 ウィンドウにグラフが表示され、そのウィンドウを選択した状態で何かキーを押すと終了します。

レポート課題

各回で、以下のような形式でレポートをまとめてください。最低限、基本課題（単に「課題」と書いているもの）について取り組むようにしてください。

  1. 第1章（導入）：その回で扱ったモデル（微分方程式）と数値解法を、自分の言葉で説明する
  2. 第2章（手法）：テンプレートからどこをどう改造したか、変更点を具体的に示す
  3. 第3章（結果）：実行した結果をグラフとともに示す
  4. 第4章（議論・考察）：結果から読み取れることと、モデルの限界・改善案について考察する

第2回・第3回では、Euler法と改良した解法（またはEuler法とパラメータ違い）を比較し、 違いが生まれる理由を数式のレベルで説明できるとなお良いです。

レポートは、印刷したものを330室前のレポートボックスに提出してください。期限は第3回翌週（月曜）の11時です。
