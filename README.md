# 地球と惑星のモデリング（情報工学実験・全3回）

情報工学科4年生向け「情報工学実験」の教材ページです。地球のエネルギー収支モデルと
惑星の重力多体問題を題材に、C言語での数値シミュレーションとgnuplotによる可視化を
全3回（各回1.5時間×2コマ）で扱います。各回の資料は回ごとの別ページになっています。

## ページ構成

| ページ | 内容 |
| --- | --- |
| `index.html` | 実験の概要、各回へのリンク、スケジュール、gnuplotのインストール（Windows）、レポート課題、付録（物理定数）、参考図書 |
| `day1.html` | 第1回 地球のエネルギー収支モデル |
| `day2.html` | 第2回 Euler法とエネルギーバランスモデルの時間発展（発展：氷アルベドフィードバック） |
| `day3.html` | 第3回 惑星の運動（重力多体問題）：Euler法 → リープ・フロッグ法（発展：N体） |

全ページ共通のメニュー（現在のページをハイライト）と、各回ページ下部の「前へ／次へ」リンクがあります。

## フォルダ構成

```
.
├── index.html, day1.html, day2.html, day3.html   公開するページ本体（ビルド済み、そのまま公開できます）
├── style.css                                     共通スタイルシート
├── vendor/katex/                                 数式レンダリング用のKaTeX本体（CDNを使わずリポジトリに同梱）
├── code/                                         配布用のCの雛形（3本）とgnuplotスクリプト（8本）。解答例は含まない
├── templates/                                    各ページの本文（編集するのはここ）
└── build.py                                      templates/ と code/ から各HTMLページを生成するスクリプト
```

## 編集とビルド

各ページの本文は `templates/` 内の `index.html`, `day1.html`, `day2.html`, `day3.html` にあります。
共通のヘッダー・メニュー・前後ページ送り・フッターは `build.py` が付与します（メニュー項目や
ページのタイトル・前後関係は `build.py` 冒頭の `NAV` と `PAGES` で定義しています）。

本文中の `{{FILE:ファイル名}}` の部分には、`code/` 内の同名ファイルの内容がそのまま埋め込まれます。

改造課題には解答例を載せず、代わりに「出力仕様」ボックス（出力ファイル名・列・計算条件・行数・自己チェック値）を
置いています。仕様を満たす出力であれば `code/` のgnuplotスクリプトがそのまま動作します。
本文やコードを修正したら、以下のコマンドでHTMLを再生成してください。

```bash
python3 build.py
```

数式はKaTeXで組版しています。本文中では `$ ... $`（インライン）・`$$ ... $$`（別行立て）の
LaTeX記法で書きます。KaTeXは `vendor/katex/` に同梱しており、外部CDNに依存しないため、
教室のネットワークが不安定でも数式の表示が崩れません。
