座学：放射平衡モデル

惑星が太陽から受け取るエネルギーと、惑星自身が宇宙空間へ放出するエネルギーが釣り合っている状態を 「放射平衡」と呼びます。太陽定数（惑星の軌道での単位面積あたりの日射量）を $S$、 惑星表面のアルベド（反射率）を $\alpha$ 、惑星の半径を$R$とすると、惑星が単位時間あたりに吸収するエネルギーは 次のように書けます。

$$S(1-\alpha)\cdot \pi R^2.$$

一方、温度 $T$ の物体が黒体放射として単位面積あたりに放出するエネルギーは、シュテファン・ボルツマンの法則より

$$\varepsilon \sigma T^4$$

です（$\varepsilon$は放射率、$\sigma$はシュテファン・ボルツマン定数）。惑星全体の表面積は $4\pi R^2$ なので、 惑星全体が放出するエネルギーは $4\pi R^2\cdot\varepsilon\sigma T^4$ になります。 この2つが釣り合う（吸収 = 放出）と置くと

$$S(1-\alpha)\,\pi R^2 = 4\pi R^2\,\varepsilon\sigma T^4$$

となり、$R$ が消えます。これを $T$ について解くと、

$$T = \left[\frac{S(1-\alpha)}{4\varepsilon\sigma}\right]^{1/4}$$

という平衡温度の式が得られます。これが今日の出発点です。

実験1：平衡温度を計算する

まずは上の式をそのままCのプログラムにしただけの、最も単純なテンプレートを動かしてみましょう。 定数を代入して T を1回計算し、表示するだけのプログラムです。

day1_eq_temp_base.c ダウンロード 
/*
 * day1_eq_temp_base.c
 * 第1回: 地球のエネルギー収支モデル（0次元モデル）
 *
 * 放射平衡の式  S(1-a)/4 = eps * sigma * T^4  を解いて
 * 平衡温度 T を1回だけ計算する、最も単純な version。
 */
#include <stdio.h>
#include <math.h>

int main(void)
{
    double S       = 1361.0;            /* 太陽定数 [W/m^2] */
    double albedo  = 0.30;              /* アルベド（無次元） */
    double epsilon = 1.0;               /* 放射率（無次元） */
    double sigma   = 5.670374419e-8;    /* シュテファン・ボルツマン定数 [W/(m^2 K^4)] */

    double T = pow(S * (1.0 - albedo) / (4.0 * epsilon * sigma), 0.25);

    printf("S = %.1f W/m^2, albedo = %.2f, epsilon = %.2f\n", S, albedo, epsilon);
    printf("-> 平衡温度 T = %.2f K (%.2f C)\n", T, T - 273.15);

    return 0;
}

このプログラムをコンパイル・実行し、地球の平衡温度（およそ255K、摂氏でおよそ−18℃）が計算されることを確認してください。

確認してみよう 実際の地球の平均気温（約15℃、288K）と比べて、計算結果はかなり低い値になっているはずです。 このズレはなぜ生まれるのでしょうか？ （ヒント：このモデルが置いている仮定と、実際の地球とを比べてみましょう。 albedoやepsilonの値を変えると、計算結果がどう変わるかも試してみてください。）
考察の答えを見る このモデルには大気の温室効果が入っていません。epsilonを1より小さくすると 温室効果を簡易的に表現でき、計算結果が実際の気温に近づきます。

課題1：太陽定数を振ってグラフにする

改造のポイント day1_eq_temp_base.cを改造して、太陽定数 S をある範囲でループさせながら 平衡温度 T を計算し、(S, T)の組をファイルに書き出すプログラムにしてください。 具体的には、(1) 平衡温度の計算を関数として切り出す、(2) fopenでファイルを開く、 (3) for文でSを少しずつ増やしながらfprintfで書き出す、という3点を追加します。
出力仕様

この仕様どおりにファイルを出力すれば、このページに掲載しているgnuplotスクリプトがそのまま動作します。解答例は示しませんので、仕様を頼りに、自分のプログラムを完成させてください。

出力ファイルeq_temp.dat（プログラムを実行したフォルダに作成）
書式テキストファイル、空白区切り、1行に1データ。#で始まる行はコメントとして扱われ、gnuplotは無視します（見出し行を入れても構いません）。
列1列目：太陽定数 S [W/m²]　／　2列目：平衡温度 T [K]
計算条件albedo = 0.30、epsilon = 1.0。Sは800から2000まで10刻み（両端を含む）
データ行数121行（コメント行を除く）
自己チェックS = 800 のとき T ≈ 222.9 K、S = 2000 のとき T ≈ 280.3 K

行数が120行になる場合は、ループの終了条件（<=か<か）を見直してみましょう。

出力されたeq_temp.datは、以下のgnuplotスクリプトでグラフにできます。

day1_plot_eq_temp.gp ダウンロード 
# day1_plot_eq_temp.gp
# 改造課題で作成したプログラムが出力する eq_temp.dat（1列目: S, 2列目: T）を可視化する。
# 使い方: gnuplot day1_plot_eq_temp.gp

set encoding utf8
set title "太陽定数 S と平衡温度 T の関係"
set xlabel "太陽定数 S [W/m^2]"
set ylabel "平衡温度 T [K]"
set grid
set key left top

plot "eq_temp.dat" using 1:2 with lines lw 2 title "T(S)  (albedo=0.30)"

pause -1 "何かキーを押すと終了します"

発展課題

アルベド $\alpha$ や放射率 $\varepsilon$ を変えると T–S 曲線はどう変わるでしょうか。 金星（$\alpha \approx 0.75$）・地球（$\alpha \approx 0.30$）・火星（$\alpha \approx 0.25$）のアルベドと実際の太陽定数を使って 平衡温度を計算し、実際の観測される温度と比較してみましょう。
