この回のねらい

  • 常微分方程式を数値的に解く最も基本的な方法（Euler法）の仕組みと限界を理解する
  • 「テンプレートの一部分を書き換えるだけで別の物理現象を解ける」ことを体験する
  • 単純なフィードバック（氷アルベドフィードバック）が非線形な振る舞い（ヒステリシス）を生むことを見る

座学：Euler法

時間とともに変化する量 $T(t)$ が、常微分方程式

$$\frac{dT}{dt} = f(T)$$

に従うとします。Euler法は、時刻を $\Delta t$ ずつの小さな刻みに区切り、各ステップで

$$T_{n+1} = T_n + \Delta t \cdot f(T_n)$$

と更新していくだけの、最も単純な数値解法です。「現在の傾き $f(T_n)$ を使って、 $\Delta t$ だけ先の値を直線近似で予測する」という考え方で、for文1つで実装できます。 刻み幅 $\Delta t$ を大きくしすぎると、この直線近似の誤差が蓄積し、計算が振動したり発散したりする （数値的に不安定になる）ことが知られています。

実験1：ニュートンの冷却則でEuler法を確認する

まずは挙動が直感的にわかりやすい題材として、周囲より温度の高い物体が徐々に冷えていく 「ニュートンの冷却則」 $\dfrac{dT}{dt} = -k(T - T_{\text{env}})$ をEuler法で解いてみます。 このプログラムの構造（forループでtとTを少しずつ更新していく部分）を、 このあとの放射収支モデルにも、次回の重力多体問題にも、そのまま使い回します。

day2_newton_cooling.c ダウンロード 
/*
 * day2_newton_cooling.c
 * 第2回: Euler法の確認用テンプレート
 *
 * ニュートンの冷却則  dT/dt = -k (T - T_env)  を
 * 陽的Euler法（前進差分）で数値的に解く、最も単純な例。
 * この構造（forループで t, T を少しずつ更新していく）を
 * このあとの課題でそのまま使い回す。
 *
 * 改造課題: dt（時間刻み）を大きくしてみるとどうなるか確認しよう。
 *           ある程度以上大きくすると、Tが振動したり発散したりする
 *           （数値不安定）ことを確認する。
 */
#include <stdio.h>

int main(void)
{
    double T     = 350.0;   /* 初期温度 [K] */
    double T_env = 300.0;   /* 周囲の温度 [K] */
    double k     = 0.05;    /* 冷却係数 [1/s] */
    double dt    = 1.0;     /* 時間刻み [s] （ここを変えて安定性を確認） */
    double t_end = 200.0;   /* 計算を終了する時刻 [s] */

    FILE *fp = fopen("cooling.dat", "w");
    if (fp == NULL) {
        fprintf(stderr, "output file cannot be opened.\n");
        return 1;
    }

    fprintf(fp, "# t[s]  T[K]\n");
    for (double t = 0.0; t <= t_end; t += dt) {
        fprintf(fp, "%.3f %.6f\n", t, T);

        double dTdt = -k * (T - T_env);   /* f(T) = dT/dt */
        T = T + dt * dTdt;                /* Euler法の更新式: T_{n+1} = T_n + dt * f(T_n) */
    }

    fclose(fp);
    printf("cooling.dat を出力しました。\n");
    return 0;
}

確認してみよう プログラム中のdtの値を少しずつ大きくして実行し直してみてください。 ある値を超えると、Tが滑らかに減少するのではなく振動し始め、さらに大きくすると発散してしまうはずです。 これがEuler法の数値不安定です。どのくらいのdtから様子がおかしくなるか、実際に確かめてみましょう。

課題1：放射収支モデルへの拡張

第1回では、吸収する日射と放出する赤外放射が釣り合った「平衡」の状態だけを調べました。 釣り合っていないとき、温度は時間とともにどう変化するのでしょうか。エネルギー保存則から考えてみます。

地表の面積 $1\,\mathrm{m}^2$ あたりの熱容量（温度を $1\,\mathrm{K}$ 上げるのに必要なエネルギー）を $C$ [J/(m$^2$ K)] とすると、この部分が蓄えている熱エネルギーは $CT$ です。 これが増える速さは、入ってくるエネルギーと出ていくエネルギーの差に等しいので、

$$C\frac{dT}{dt} = (\text{吸収する日射}) - (\text{放出する赤外放射})$$

と書けます（どちらも単位面積・単位時間あたりのエネルギー、つまり W/m$^2$ です）。 第1回で見たように、惑星全体で吸収する日射 $S(1-\alpha)\pi R^2$ を表面積 $4\pi R^2$ で割ると、 単位面積あたり $S(1-\alpha)/4$ になります。放出する赤外放射は単位面積あたり $\varepsilon\sigma T^4$ なので、

$$C\frac{dT}{dt} = \frac{S(1-\alpha)}{4} - \varepsilon\sigma T^4$$

が得られます。右辺が0になる温度が、第1回で求めた平衡温度です。$T$ がそれより低ければ右辺は正（温度が上がる）、 高ければ負（温度が下がる）ので、$T$ は平衡温度に近づいていくはずです。 両辺を $C$ で割れば $\dfrac{dT}{dt} = f(T)$ の形になり、前節のEuler法でそのまま解けます。 $C$ は、深さ100 m程度の海洋の混合層を想定し、水の密度 $10^3\,\mathrm{kg/m^3}$ と比熱 $4\times10^3\,\mathrm{J/(kg\,K)}$ から $C \approx 4\times10^{8}$ J/(m$^2$ K) とします。

改造のポイント day2_newton_cooling.cの更新式（T = T + dt * dTdt;）はそのままに、 dTdtの中身だけを、上で導いた式の右辺 $\dfrac{1}{C}\left[\dfrac{S(1-\alpha)}{4} - \varepsilon\sigma T^4\right]$ に置き換えてください。 冷却則が「周囲との温度差に比例して冷える」モデルだったのに対し、 今度は「吸収する日射」と「放出する赤外放射」の差で温度が変化するモデルになります。

発展課題：氷アルベドフィードバックとヒステリシス 発展

ここまでは、アルベド$\alpha$を定数として扱ってきました。しかし実際の地球では、表面が氷や雪に覆われれば白くなって アルベドが上がり、氷が融ければアルベドは下がります。つまり$\alpha$は温度$T$に依存します。 この「温度が下がる → 氷が増える → アルベドが上がる → 日射を反射して、さらに温度が下がる」という 正のフィードバックをモデルに組み込むと、何が起きるかを調べます。

1. アルベドを温度の関数にする。 最も単純なモデルとして、低温側（氷あり）ではアルベドを$\alpha_{\text{ice}}$、高温側（氷なし）では$\alpha_{\text{water}}$とし、 その間の温度範囲では直線でつなぐことにします。

$$\alpha(T)=\begin{cases} \alpha_{\text{ice}} & (T\le T_{\text{ice}})\\[2pt] \alpha_{\text{ice}}+(\alpha_{\text{water}}-\alpha_{\text{ice}})\dfrac{T-T_{\text{ice}}}{T_{\text{water}}-T_{\text{ice}}} & (T_{\text{ice}}\lt T\lt T_{\text{water}})\\[2pt] \alpha_{\text{water}} & (T\ge T_{\text{water}}) \end{cases}$$

パラメータの値は、下の出力仕様に示します。基礎方程式は課題1の式の$\alpha$を$\alpha(T)$に置き換えるだけです。

$$C\frac{dT}{dt} = \frac{S\,\bigl(1-\alpha(T)\bigr)}{4} - \varepsilon\sigma T^4$$

2. 平衡状態はいくつあるか。 平衡状態とは、右辺が0になる（吸収する日射 = 放出する赤外放射）温度のことです。 下の図は、$S=2000\ \text{W/m}^2$の場合について、吸収と放出を温度の関数として描いたものです （この図はモデルの式から計算した曲線で、実測データではありません）。

アルベドが一定なら、吸収の曲線は水平な直線なので、交点は常に1つだけです。 ところが$\alpha(T)$が温度とともに下がると、吸収の曲線は$T_{\text{ice}}$〜$T_{\text{water}}$の間で立ち上がり、 放出の曲線と3回交わることがあります。$S$を変えると、吸収の曲線が上下に動きます。 $S$が小さいと冷たい解だけ、大きいと暖かい解だけが残り、その中間の範囲では 安定な平衡状態が2つ同時に存在します。

3. ヒステリシスの発生。 安定な解が2つあるとき、どちらに落ち着くかは「初期値」、つまりそれまでの経緯で決まります。 そこで、太陽定数$S$をゆっくり変えながら、各$S$での平衡温度を追いかけます。 $S$を小さい側から増やしていくと、温度は冷たい解に乗ったまま上がり、その解が消える$S$で 暖かい解へ一気にジャンプします。逆に、$S$を大きい側から減らしていくと、暖かい解に乗ったまま下がり、 その解が消える$S$で冷たい解へジャンプします。2つのジャンプが起きる$S$が異なるため、 増やす場合と減らす場合で、同じ$S$でも違う温度になる区間（ヒステリシス）が生まれます。

改造のポイント 課題1で作ったプログラムの定数だったalbedoを、上の$\alpha(T)$にあたる関数albedo(T)に 置き換えます。さらに、太陽定数Sを外側のループでゆっくり変化させ、各SでTが平衡に近づくまでEuler法で 時間積分する、という2重ループの構造にします。ポイントは、次のSでは、直前のSで得られたTを 初期値として引き継ぐことです（毎回初期化すると、「経緯」が失われてヒステリシスが現れません）。 Sを増加させていく場合と減少させていく場合とで、それぞれ結果をファイルに記録してください。

見えてくること Sを増加させていく場合と減少させていく場合とで、同じ太陽定数でも異なる平衡温度に落ち着く 区間が現れ、グラフ上に「ジャンプ」を伴うループ（ヒステリシス）が現れます。 これは、ある太陽定数のもとでは「凍った地球（スノーボール・アース）」と「凍っていない地球」の両方が 安定な平衡状態になりうることを意味しています（多重平衡）。これは単純な線形モデルからは出てこない、 フィードバックのある非線形システムに特有の振る舞いです。
